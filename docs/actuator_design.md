# QDD 액추에이터 설계 문서

## 개요

QDD(Quasi Direct Drive) 액추에이터는 낮은 감속비(6~9:1)의 벨트 전동을 사용하여
높은 백드라이브 가능성과 충격 흡수 능력을 제공한다.

## 구성 요소

| 부품 | 사양 | 비고 |
|------|------|------|
| BLDC Motor | KV 값 TBD | 직경/길이 제약 검토 필요 |
| 엔코더 | AS5047P or AS5048A | SPI 통신, 14bit |
| 감속기 | 벨트 + 풀리 (6~9:1) | 치형 벨트 검토 |
| 드라이버 | ESP32 + DRV8302/STSPIN | SimpleFOC 호환 |
| 전류 감지 | 인라인 션트 | 3-shunt 방식 |

## 목표 스펙

| 항목 | 목표값 | 비고 |
|------|--------|------|
| 연속 토크 | 3~6 N·m | 열 제한 |
| 피크 토크 | 10~15 N·m | 순간 |
| 출력 속도 | 20~40 rad/s | 부하 시 |
| 감속비 | 6~9:1 | |
| 백드라이브 토크 | < 0.5 N·m | 목표 |
| 질량 | < 400g | 목표 |

## AS5047P SPI 연결

```
AS5047P → ESP32
MISO    → GPIO 19
MOSI    → GPIO 23
SCK     → GPIO 18
CS      → GPIO 5
```

## FOC 제어 구조

```
목표 토크
    ↓
d-q 전류 제어 (PI)
    ↓
SVPWM
    ↓
3상 인버터 (DRV8302)
    ↓
BLDC Motor
    ↑
SPI 엔코더 → 전기각 추정
```
